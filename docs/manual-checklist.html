Smoke Test Nhanh — Terminal (chạy 1 lệnh)
DATE=$(date +%Y-%m-%d) BASE="https://opta-api.uniscore.vn/api/v2/sport/football/scheduled-events-pagination-v2" for LOCALE in VN BR AR US MX JP; do R=$(curl -s -X POST "$BASE/$DATE/locale/$LOCALE/type/upcoming" \ -H "Content-Type: application/json" \ -d '{"sortByMatchTime":false}') CODE=$(echo "$R" | python3 -c "import sys,json; print(json.load(sys.stdin)['code'])" 2>/dev/null) EV=$(echo "$R" | python3 -c "import sys,json; d=json.load(sys.stdin)['data']; print(len(d.get('events',[])))" 2>/dev/null) OC=$(echo "$R" | python3 -c "import sys,json; d=json.load(sys.stdin)['data']; print(sum(x['match_count'] for x in d.get('otherCompetitions',[])))" 2>/dev/null) TT=$(echo "$R" | python3 -c "import sys,json; print(json.load(sys.stdin)['data']['pagination']['total'])" 2>/dev/null) DIFF=$(python3 -c "print(abs($((EV+OC)) - $TT))" 2>/dev/null) echo "[$LOCALE] code=$CODE events=$EV otherComps=$OC counted=$((EV+OC)) total=$TT diff=$DIFF" done
Kết quả mong đợi: mỗi dòng có code=1 và diff ≤ 5
